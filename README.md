# Crazy Cattle 3

Браузерная 3D-игра по мотивам овечьего батл-рояля. Самостоятельная фан-версия; не официальный релиз CrazyCattle3D.

24 овцы на сужающейся арене, рывки, столкновения и выталкивание за край. Три пастбища с разной инерцией, боты, мини-карта, мобильный джойстик, пауза, звуковые эффекты и локальные рекорды.

## Локальный запуск

```sh
python3 -m http.server 8080 --directory dist
```

Открыть http://localhost:8080. Установка зависимостей и сборка не требуются. Three.js включён в `dist/vendor/` под лицензией MIT, которую сохраняет исходный файл библиотеки.

## Управление

- WASD / стрелки — движение
- Пробел — рывок; перезарядка 3 секунды
- Q / E — повернуть камеру
- Esc — пауза
- На телефоне — джойстик и кнопка рывка

Рекорды и настройки сохраняются в localStorage. Соперники управляются ботами; сетевой режим не используется.

## Проверка механики

```sh
node --test tests/core.test.mjs
```
