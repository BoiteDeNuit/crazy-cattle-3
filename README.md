# Crazy Cattle 3

Браузерная фан-версия по мотивам CrazyCattle3D. Самостоятельная реализация механик; не официальный релиз и не перенос исходного кода оригинала.

## Версия 2

- Большие постоянные пастбища: радиус 54, 60 и 66 вместо 23.
- Камера следует позади овцы и поворачивается вместе с её направлением.
- Плавный разгон, инерция, спринт, прыжок с тараном и физические столкновения.
- Удары создают угловой импульс: овца кренится, может восстановить равновесие или перевернуться.
- Переворот и касание сплошного пограничного забора вызывают взрыв и выбывание.
- Ударная волна взрыва толкает соседних овец; нокауты учитывают автора удара.
- Холмы, склоны и дюны используют общую высоту поверхности для изображения и физики.
- Ирландия: 30 овец. Швеция: 40. Египет: 50.
- Трофеи и лучшее время для каждого пастбища сохраняются в браузере.
- Мини-карта, индикаторы скорости и наклона, мобильный джойстик, пауза и повтор матча.

## Запуск

```sh
python3 -m http.server 8080 --directory dist
```

Открыть http://localhost:8080. Сборка и установка зависимостей не нужны. Three.js включён локально; лицензия находится в `dist/vendor/THREE-LICENSE.txt`.

## Управление

- W / стрелка вверх — разгон
- S / вниз — тормоз и задний ход
- A / D, влево / вправо — повернуть овцу вместе с камерой
- Перетаскивание мышью по полю — поворот
- Shift — спринт
- Пробел — прыжок с тараном
- Q / E — наклоны для восстановления равновесия
- B — блеять
- Esc / P — пауза
- R / Enter / пробел после выбывания — новый матч
- Телефон: джойстик для разгона и поворота, кнопка для тарана

Настройки, рекорды и трофеи хранятся в localStorage. Соперники — боты.

## Проверки

```sh
node --test tests/core.test.mjs
node --check dist/game.js
```

Проверяются камера за овцой, инерция при повороте, спринт и прыжок, постоянный размер пастбища, перевороты, взрывы от забора, ударные волны, начисление нокаутов, склон поверхности и численная устойчивость всех трёх карт.
